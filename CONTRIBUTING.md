# Contributing

Pull requests are welcome. **One maintainer, no service-level agreement** — expect a reply in
days rather than hours, and expect some to be declined. If a change is large, open an issue
first so the shape can be argued before you have written it.

## Before you open one

```bash
make check       # ruff + ruff format + mypy strict + pytest
make web-check   # tsc + eslint + node:test
```

Both must pass. CI runs the same two commands plus the browser tests, so a green local run is
the whole gate. `make help` lists everything else.

The browser tests need a database and a running API — see the `web` job in
`.github/workflows/ci.yml` for the exact sequence, including `COOKIE_SECURE=0`, without which
Chromium discards the session cookie over plain HTTP and every account test fails silently.

## Things this project will not accept

These are not style preferences. Each one is load-bearing, and a change that undoes one will
be declined however well it is written.

- **No heuristic that repairs an unverifiable quote.** A quote the validator cannot locate in
  the source text is discarded, always. A tool that reports language techniques in named
  outlets cannot cite sentences they never published, and this is also the only defence
  against prompt injection that does not depend on the model cooperating.
- **No claim about a publisher.** Every public statement is about a sentence. The interface
  never aggregates by outlet, never ranks, and there is no public API — because a
  machine-readable endpoint serving everything would make that constraint unenforceable.
  Aggregates exist only in the operator panel, as diagnostics of the model.
- **The model is never told which outlet published the text.** `source_label` exists so the
  brand-bias probe can measure what happens when it is, and for nothing else.
- **No source ships enabled.** Enabling one is an operator's decision with an operator's
  duties attached. See [COMPLIANCE.md](COMPLIANCE.md).
- **A response that fails to parse is recorded, not repaired.** Its usual causes are
  configuration faults, and patching the JSON hides the signal saying which setting is wrong.

## Changing the analysis contract

The taxonomy lives in three places and they move together, or the system is broken in a way
no test will notice until production:

1. `AnalysisResult` in `src/domain/analysis.py` — generates the schema sent to the model
2. the `CHECK` constraint in `migrations/001_init.sql` — plus a new migration for existing rows
3. the prompt text in `prompts/` — what the model is actually asked for

Enum *values* are the wire format. They are not display strings; the front end translates them
through `web/messages/`.

## Changing a prompt

Any wording change bumps `PROMPT_VERSION` and lands with a measurement. Without the bump there
is no way to tell whether an edit helped, and `analyses.prompt_version` stops meaning anything.

Never delete a file from `prompts/`. Stored analyses point at them by version, and one whose
prompt is gone cannot be reproduced.

Quality figures live in [MODEL_CARD.md](MODEL_CARD.md) and in `web/messages/`. If a change
moves them, both change in the same pull request — the interface must not quote a number
measured against a configuration it is no longer running.

## Style

- Python: type hints everywhere, `mypy --strict` passes, no bare `except`, Pydantic at every
  data boundary. Formatting is `ruff format`; do not argue with it.
- TypeScript: no `any`. Types for the API come from `web/lib/api-types.ts`, generated by
  `make api-types`. Nothing about the contract is retyped by hand.
- **Comments explain why, never what**, and in English. A comment that restates the line below
  it will be asked for removal; a comment recording a decision the code cannot show is the
  reason the codebase is navigable.
- Polish is for prompt text, contract values, and generated reports. Everything else —
  identifiers, comments, documentation, API field names — is English.
- Tests assert properties, not transcripts. Temperature 0.1 is not determinism.

## What is not in this repository

`docs/` holds local working notes and the reports `make audit-sources` and `make eval-report`
regenerate. It is deliberately absent, and nothing in the code should link into it.
